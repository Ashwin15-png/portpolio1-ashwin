## 🚀 Flagship Projects

<br />

### ⚙️ VibeGuard AI
> **Enterprise Industrial IoT / Predictive Maintenance Platform**

An industrial IoT telemetry monitoring system built to track equipment health metrics, detect operational anomalies, calculate Exponential Moving Averages (EMA), perform sustained anomaly validation, and stream live predictive analytics via WebSockets.

**Key Architecture Highlights:**
- 📡 Real-time telemetry ingestion pipeline with Socket.IO & Node.js backend
- 🔍 EMA filtering algorithm & sustained anomaly validation logic
- 📊 Predictive machine health index & Remaining Useful Life (RUL) estimation
- 🗄️ Scalable historical telemetry store backed by MongoDB Atlas
- 🖥️ High-responsiveness React interactive industrial monitoring dashboard

**Tech Stack:** `React` · `Node.js` · `Express` · `Socket.IO` · `MongoDB`

### 📑 PrescriptionX
> **AI Healthcare / Medical OCR & Document Intelligence Platform**

An automated AI-driven medical prescription extraction platform designed to preprocess prescription document scans, run Optical Character Recognition (OCR), extract key medical entities, and serve high-concurrency API requests.

**Key Architecture Highlights:**
- 🔍 Image preprocessing & noise reduction pipeline built with OpenCV
- 🤖 Optical Character Recognition engine powered by Tesseract OCR
- ⚡ High-throughput REST endpoints built with FastAPI
- 🗄️ Relational clinical data schema & indexing structured in PostgreSQL

**Tech Stack:** `FastAPI` · `PostgreSQL` · `OpenCV` · `Tesseract OCR` · `Python`
